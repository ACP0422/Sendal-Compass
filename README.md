# SENDAL — Website + Sistema de Cotización

Sitio web inmobiliario con integración backend para consulta de información de lotes. Plataforma enfocada en presentación del desarrollo y visualización dinámica de datos.

---

## Stack

**Frontend**
- HTML  
- CSS  
- JavaScript  
- Django Templates  

**Backend**
- Python  
- Django  
- MySQL  

**Herramientas**
- Figma (Diseño UI)
